# Technischer Ansatz — vorläufig

- Ziel ist ein 3D-Spiel mit Welt-/NPC-Simulation und Coop.
- Erst mit Low-Poly-/Platzhaltermodellen Mechaniken erproben; hochwertige realistische 3D-Assets später austauschen.
- Codex soll auf Basis versionierter Design- und Entscheidungsdokumente arbeiten.
- In Technikgesprächen standen Engines (u. a. Unreal Engine 5, davor Godot) zur Diskussion; keine Engine hier als endgültig bestätigt dokumentieren.
- **Offen:** finale Engine, Projektstruktur, Gameplay-Architektur, Networking, Weltpersistenz, NPC-Simulationsansatz, Pipeline.
- Dieses Repository enthält zum jetzigen Zeitpunkt Designnotizen; die Dokumentation stellt keine fertige Spielimplementierung dar.
